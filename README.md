# Free Lineage Piece

สคริปต์ DUKE HUB สำหรับ Lineage Piece

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/weirdstorych-cyber/Free_lineage_piece/main/loader.lua"))()
```

ไฟล์หลักคือ [`poon_fe_pastefy.lua`](poon_fe_pastefy.lua) ตัวโหลด [`loader.lua`](loader.lua) จะดึงไฟล์หลักจาก branch `main` ทุกครั้งที่เรียกใช้งาน

ไฟล์หลักมีข้อความลิขสิทธิ์และใบอนุญาตของ MacLib และ IBM Plex fonts อยู่ที่ต้นไฟล์
